# A/B-тест удержания в мобильной игре Cookie Cats

## Цель проекта
Проверить, влияет ли перенос обязательных «ворот» с 30-го на 40-й уровень на удержание игроков (1-й и 7-й день).

## Данные
Датасет содержит информацию о **90 189 игроках**, случайно распределённых между двумя группами:
- `gate_30` (контроль): **44 700** игроков
- `gate_40` (тест): **45 489** игроков

Группы почти одинакового размера, что говорит о корректной рандомизации.

## Метод
Для сравнения долей удержания между группами использован критерий хи-квадрат (`scipy.stats.chi2_contingency`). Нулевая гипотеза (H0): разницы между группами нет. Уровень значимости — 0.05.

## Результаты

### 1-дневное удержание
- `gate_30`: **44.82%**
- `gate_40`: **44.23%**
- **P-value: 0.0755**

Разница статистически **незначима** (p > 0.05). На следующий день после установки обе группы возвращаются примерно одинаково.

### 7-дневное удержание
- `gate_30`: **19.02%**
- `gate_40`: **18.20%**
- **P-value: 0.0016** (хи-квадрат = 9.96)

Разница статистически **значима** (p < 0.05). В группе с воротами на 30-м уровне удержание на 7-й день **выше**.

## Вывод
Перенос ворот на 40-й уровень **ухудшает** долгосрочное удержание игроков. Рекомендация для продукта: **оставить ворота на 30-м уровне**.
